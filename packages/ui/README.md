# @sahihfolio/ui

Shared React components and design tokens for Sahihfolio web applications and interfaces.

## Structure

- `src/tokens/`: Brand colors (Deep Navy, Slate Blue, Emerald, Teal, Gold), light/dark surfaces, typography scale
- `src/components/`:
  - `Button`: Primary, secondary, outline, and ghost variants
  - `Badge`: Status badges for compliance (compliant, non_compliant, under_review, methodology_dependent)
  - `Card`: Surface container with header, title, and content subcomponents
  - `Input`: Standard accessible form input
  - `Select`: Accessible dropdown select
  - `DisclaimerBanner`: Standardized Shariah and financial non-advice notice
