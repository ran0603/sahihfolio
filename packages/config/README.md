# @sahihfolio/config

Shared ESLint, TypeScript, Tailwind, and Prettier configurations for Sahihfolio workspace packages and apps.

## Contents

- `typescript/base.json`: Base Node / TypeScript 2022 configuration
- `typescript/nextjs.json`: Next.js App Router TypeScript configuration
- `typescript/react-library.json`: React component library configuration
- `eslint/base.js`: Shared ESLint flat configuration
- `eslint/next.js`: Next.js ESLint configuration
- `eslint/react.js`: React package ESLint configuration
- `tailwind/tailwind.config.js`: Tailwind theme preset with Sahihfolio brand tokens
- `prettier/index.json`: Shared Prettier formatting rules
