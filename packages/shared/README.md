# @sahihfolio/shared

Shared domain types, Zod validation schemas, constants, and formatting utilities for Sahihfolio apps and packages.

## Exports

- `@sahihfolio/shared/constants`: Provider types, asset types, screening results, supported countries, analytics events.
- `@sahihfolio/shared/types`: TypeScript interfaces for CountryProfile, Provider, ScreeningReport, etc.
- `@sahihfolio/shared/schemas`: Zod schemas for Options Finder intake, screening queries, and email capture.
- `@sahihfolio/shared/utils`: Currency, percentage, and date formatters, slugify utility.
